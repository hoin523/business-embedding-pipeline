# Card Merchant Data

카드사 승인/매입 원천 데이터는 보통 비공개이므로, 이 프로젝트는 파일을 직접 받았을 때 같은 형식으로 학습할 수 있도록 `card`와 `corporate_card` 소스를 지원한다.

## Source Types

- `card`: 일반 카드 가맹점 데이터. `가맹점명` 또는 `카드가맹점명`을 `가맹점명:` 라벨로 변환한다.
- `corporate_card`: 법인카드/정산 파일에서 거래 상대가 `공급업체명` 또는 `거래처명`으로 내려오는 데이터. `공급업체명:` 라벨로 변환한다.

## Supported Columns

| Canonical field | Accepted Korean columns |
| --- | --- |
| `entity_name` | `가맹점명`, `카드가맹점명`, `가맹점상호`, `가맹점상호명`, `상호명`, `사용처명`, `상점명`, `매장명`, `공급업체명`, `공급자명`, `거래처명` |
| `industry_name` | `업종명`, `업종`, `카드업종명`, `카드사업종명`, `가맹점업종명`, `가맹점업종`, `가맹점유형명`, `가맹점유형`, `MCC명`, `MCC업종명` |
| `industry_code` | `업종코드`, `카드업종코드`, `카드사업종코드`, `가맹점업종코드`, `가맹점유형코드`, `MCC`, `MCC코드` |
| `item_name` | `품목명`, `상품명` |

## Examples

```text
카드가맹점명,가맹점업종명,MCC코드
보나비,일반한식,5812
```

becomes:

```text
가맹점명: 보나비 | 업종명: 일반한식
```

```text
공급업체명,카드업종명,품목명
한국식품유통,식자재 도매업,급식재료
```

becomes:

```text
공급업체명: 한국식품유통 | 업종명: 식자재 도매업 | 품목명: 급식재료
```
